# TermuX

Mobile development environment based on Termux. Build, compile, and run code directly on your Android device — no PC needed.

| Key | Value |
|---|---|
| Package | `com.ccompile.lite` |
| Application ID | `com.ccompile.lite` |
| Min SDK | API 24 (Android 7.0) |
| Target SDK | API 28 |
| Language | Kotlin |
| Base | [Termux](https://github.com/termux/termux-app) terminal emulator |

## Credits

This project uses the Termux terminal emulator source code.
All credits to the [Termux project](https://github.com/termux) contributors.

## Features

- Full Linux terminal environment on Android
- File manager with archive extraction (tar.gz, tar.xz, zip, 7z)
- Multi-session terminal support
- Package installation via `pkg`
- NDK toolchain support
- No root required
